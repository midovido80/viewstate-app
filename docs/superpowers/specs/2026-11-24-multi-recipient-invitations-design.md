# اختيار عدة زملاء للدعوة

اعتمد المستخدم المسار في المحادثة وطلب تنفيذه دون نشر أو تثبيت: اختيار واحد أو أكثر من سجل الهاتف أو الأشخاص المحفوظين، وإرسال دعوات التطبيق دفعة واحدة، وفتح واتساب برسالة مستقلة يؤكد المستخدم إرسالها هناك.

## السلوك المعتمد

- اختيار الدائرة، ثم مصدر الأشخاص: «الأشخاص عندي» أو «سجل الهاتف»، مع بحث بالاسم والرقم وتحديد متعدد. الأشخاص المحفوظون ليسوا دليلًا على وجود حساب ViewState.
- كل رقم ظاهر اختيار مستقل؛ لا اختيار تلقائي لرقم واحد عند وجود عدة أرقام. الأرقام المكررة بين المصدرين مستلم واحد، وتبقى الاختيارات عند تبديل المصدر أو البحث.
- قراءة سجل الهاتف بإذن يطلبه المستخدم، دون استيراد تلقائي إلى الأشخاص أو رفع سجل الهاتف. رفض الإذن أو محدوديته لا يمنع اختيار الأشخاص المحفوظين. الويب يعرض أن سجل الهاتف غير متاح.
- مراجعة المختارين قبل الإرسال، مع عددهم وإمكان إزالة أي مستلم. حد الدفعة 50 رقمًا؛ حد الدعوات المباشرة الحالي 10 محاولات لكل مالك خلال 24 ساعة يبقى كما هو.
- زر دعوة التطبيق يرسل دفعة واحدة إلى الخادم. النتيجة لكل رقم: «تمت معالجة الطلب» أو «وصلت حد الدعوات»؛ لا تأكيد لتسجيل الرقم أو وصول الدعوة. استعادة الرد المفقود بنفس العملية لا تستهلك الحصة ولا تعيد الدعوات.
- واتساب يفتح لكل مستلم بفعل صريح رسالة برابط مستقل. التطبيق يعرض «تم فتح واتساب» ولا يدّعي إرسال الرسالة. تكرار الفتح يعيد استخدام رابط المستلم نفسه، مع إتاحة مشاركة النص عند تعذّر الفتح.
- تبديل الحساب أو إغلاق الشاشة يبطل نتائج العمليات القديمة. تغيير الدائرة لا يعيد استخدام روابط الدائرة السابقة.

## النهج

اختير توسيع مسار الدعوة الحالي مع منتقي متعدد وطلب خادم واحد للدعوات المباشرة. فتح واتساب يجري لكل مستلم ليحتفظ المستخدم بتأكيد الإرسال. إرسال رسائل واتساب آليًا أو إضافة دليل عام لحسابات المستخدمين ليسا ضمن الطلب.

تستخدم الواجهة Expo Contacts المثبتة حاليًا، وتطبيع الهاتف الموجود وموارد التخزين المعزولة للحساب. لا مكتبات أصلية جديدة ولا تعديل هوية التطبيق أو مزوّد المصادقة.

## التحقق وحدود التسليم

اختبارات للدمج والتطبيع والاختيار المتعدد، والإذن المرفوض/المحدود، وتكرار النقر وإعادة المحاولة، وخصوصية دفعة الخادم وصلاحياتها وحصتها، وروابط واتساب المنفصلة وتبديل الحساب. تشغيل كامل اختبارات الموبايل وTypeScript ونطاق العقارات وPostgreSQL، وفحص الواجهة ببيانات وهمية. لا دعوات فعلية أثناء الاختبار، ولا هجرة مستضافة أو تحديث هاتف أو تثبيت APK.
