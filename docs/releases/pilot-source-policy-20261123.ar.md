# مصدر العمل والنشر المعتمد

بناءً على طلب المستخدم في 23 نوفمبر 2026، أصبح `codex/latest-pilot-2026-11-23` الفرع الافتراضي في GitHub ومصدر العمل والنشر والمعاينة. أكدت صفحة إعدادات GitHub نجاح التغيير، وأعاد `git ls-remote --symref origin HEAD` الاسم نفسه. جرى تحديث `origin/HEAD` المحلي ليتتبعه.

ملف `pilot-source.json` يجمع اسم المستودع والفرع وقناة `viewstate-next-pilot` ووقت التشغيل `viewstate-next-android-1` ومنفذ المعاينة 8081. لا يغيّر ذلك هوية التطبيق أو قناة الهواتف المثبتة.

## فحص النشر

الأمر `npm run release:check` يرفض النشر عندما يكون مجلد العمل على فرع قديم أو detached HEAD، أو عندما يكون origin لمستودع آخر، أو توجد ملفات غير مسجلة، أو لا يطابق commit المحلي رأس الفرع في GitHub، أو لم يعد هذا الفرع افتراضيًا على GitHub. توجد ستة اختبارات لهذه الحالات وللسماح بمعاينة التعديلات على الفرع الصحيح.

أداة النشر `npm run release:pilot -- "Release description"` تستدعي الفحص قبل استخدام اعتماد الخادم أو تشغيل Expo. كذلك تتحقق من تطابق قناة ووقت تشغيل التطبيق مع سياسة المصدر. أداة Windows تختار هذا المستودع وتعرض الفرع والـcommit؛ ترفض نسخة قديمة لا تحمل أداة الفحص. يبقى مفتاح الخادم في التخزين الآمن، ولا يدخل حزمة التطبيق.

## المعاينة

الأمر `npm run preview:web` يتحقق من الفرع والمستودع، ثم يبني Expo Web من `artifacts/mobile` في هذا المستودع، ويخزن الناتج في `.preview/pilot-web` المتجاهل في Git. يحسب بصمة مصدر التطبيق ويتأكد من ثباتها أثناء البناء.

الخادم يستمع محليًا فقط على IPv4 وIPv6، ويمنع التخزين المؤقت. يقدم `/__source` معلومات البناء الفعلية وبصمة المصدر وحالة التقادم. إذا تغير مصدر التطبيق أو انتقل المستودع إلى فرع آخر، يرفض تقديم صفحة HTML القديمة ويطلب إعادة البناء، بدل عرضها باعتبارها أحدث نسخة.

## استمرار العمل

تحدد `AGENTS.md` المصدر المعتمد وتعليمات الفحص والنشر للأعمال التالية. عُدّل GitHub Actions ليستقبل الدفع وطلبات الدمج إلى الفرع الجديد، وأضيفت اختبارات سلامة مصدر النشر. يستخدم فحص فروق طلب الدمج فرعه المستهدف بدل افتراض `main`.

سجل بصمات 23 نوفمبر يظل سجلًا تاريخيًا للإصدار السابق. لا نعيد كتابته بعد تطوير أدوات النشر؛ الإصدارات التالية توثق مصدرها وcommit الخاص بها. تطبيق هذه السياسة لا ينشر تحديث Android جديدًا تلقائيًا، ولا يغير بيانات المستخدم أو إعدادات أذونات هاتفه.
