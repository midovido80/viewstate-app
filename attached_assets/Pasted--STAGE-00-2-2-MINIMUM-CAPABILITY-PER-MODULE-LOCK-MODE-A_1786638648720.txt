ViewState V001 is a private, per-broker, bilingual Arabic/English mobile tool for real-estate professionals.

First operational market:

Kuwait

Planned expansion region:

GCC

The product core must remain generic and extensible.

Core operating model:

Capture → Organize → Act

Capture First → Enrich Later

Approximately 10–15 seconds for BASIC capture of essential Property, Contact, or Requirement information only.

# DEFINITION OF "MINIMUM CAPABILITY"

A Minimum Capability is:

> The smallest user-meaningful behavior that makes the capability useful in V001.

It is NOT:

- a screen specification
- a list of database fields
- a database schema
- a technical implementation
- a detailed UX flow
- an architecture design
- a complete future feature set

Example of correct abstraction:

"Broker can create and later retrieve a property record."

Example of forbidden detail:

"Create a PostgreSQL properties table with title VARCHAR(150), price NUMERIC, and area_id UUID."

Example of correct abstraction:

"Broker can associate a Buyer/Tenant Requirement with the relevant contact."

Example of forbidden detail:

"Add requirement_id to contacts table and create a requirement form with 12 fields."
