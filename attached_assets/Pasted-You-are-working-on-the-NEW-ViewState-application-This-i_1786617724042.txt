# OBJECTIVE

Define the product foundation for **ViewState V001** before any implementation begins.

The product is intended primarily as a fast real-estate operating tool for a real-estate broker/consultant working daily with:

* Properties
* Property owners
* Tenants / property seekers
* Brokers and real-estate contacts
* Property requirements
* Property matching
* Follow-ups
* WhatsApp-driven real-estate communication

ViewState V001 must prioritize:

1. Extremely fast data capture.
2. Minimum friction during daily field work.
3. Simple organization of properties and contacts.
4. Fast retrieval of existing information.
5. Fast identification of useful property/client matches.
6. Mobile-first real-estate workflow.
7. Capture First → Enrich Later.
8. Avoiding unnecessary CRM complexity.

Target operational goals include:

* New-user registration/onboarding should be extremely fast.
* Adding a basic property should be possible in approximately 10–15 seconds when only essential information is available.
* Adding a basic contact/requirement should also be possible in approximately 10–15 seconds.
* The user must not be forced to complete large forms before saving useful information.
